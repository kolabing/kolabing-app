Key design decisions in this proposal

  • One base card layout — horizontal: content left, 68×68 square image right
  • Image fallback — emoji/initials on warm yellow-cream gradient when no photo
  • Pastel chips — amber (city/discount), sage (date/nature), lavender (category), blue-grey (meta), peach (food)
  • Status badge — small pill above title, always top-left
  • Actions row — compact 36px buttons, only shown for Offers (Requests/Active/Finished use chevron tap)
  • Request cards — same layout, circular avatar replaced by square kolab cover image
